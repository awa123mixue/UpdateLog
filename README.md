# 遗忘世界丨8月21日更新日志

致各位玩家们
感谢大家一直以来对我们的支持与热爱！
在认真收集了社区反馈、数据表现和长期规划之后，我们带来了本次 「 8月21日 」 小版本更新。

本次更新不包含新内容，也涉及大量底层优化和部分系统的移除——每一处移除都经过慎重考量，目的是让游戏更轻量、更长久。
请各位耐心阅读，我们会在文末详细说明移除原因与补偿方案。

-- CDKEY兑换码机制
-- C00Kldd 道具
-- SoundBox 道具 [ 通行证付费 ]

功能优化与体验提升（重点）
我们始终把“流畅、舒适、合理”作为优化目标，本次共计优化 6 项 痛点：

🚀 性能优化

大幅降低低端机型发热与掉帧帧率提升约 5%~10%
资源包压缩，运行内存压缩至1.3 - 3GB空间

📱 操作便利性

支持 [ 奔跑 ] 功能

❌ 功能移除 & 系统关闭（重要说明）
为了项目长期健康，我们不得不做出一些艰难的割舍。
以下功能将在本次更新后 正式移除或关闭。我们深知这会影响部分玩家的习惯，因此每一项都附有详细理由和补偿方案。

1. 移除「R15体型设置」
📌 移除内容：R15体验玩家，默认强制R6
🕒 关闭时间：已关闭 [ 8/21 ]
🤔 移除原因：适配性太差，不敢确定未来动画与系统适配
🎁 补偿方案：无

2. 移除「Exp经验」
📌 移除内容：经验值数据移除
🕒 关闭时间：8/20
🤔 移除原因：没用

5. 其他清理项（汇总）
🗑️ 减少“频道”中的自动喊话机器人语录（非玩家）
🗑️ 关闭测试服专用调试指令（不影响正常玩家）

致歉与理解
我们比任何人都清楚，每一次移除都会打破一部分玩家的习惯。
但请相信：移除 ≠ 抛弃，而是为了给新内容、更好的底层架构腾出空间。
